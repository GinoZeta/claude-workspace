# CLAUDE - Espacio de trabajo con IA

Este repositorio contiene el espacio de trabajo personal de Gino Zeta para colaborar con Claude Code.

## Descripción

Directorio de trabajo utilizado para explorar automatizaciones, scripts y mejoras asistidas por inteligencia artificial en el contexto de Distribuidora Andes Films Bolivia.

## Uso

Este espacio sirve como base para:

- Experimentos con Claude Code CLI
- Scripts de automatización
- Documentación de flujos de trabajo

## Requisitos

- [Claude Code](https://claude.ai/code)
- Git
- GitHub CLI (`gh`)

## Inicio rápido

```bash
# Clonar el repositorio
git clone https://github.com/GinoZeta/claude-workspace.git

# Entrar al directorio
cd claude-workspace

# Abrir con Claude Code
claude .
```
