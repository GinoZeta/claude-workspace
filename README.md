# claude-workspace

Espacio de trabajo personal de Gino Zeta para colaborar con Claude Code en el contexto de Distribuidora Andes Films Bolivia.

## Uso

Este espacio sirve como base para:

- Experimentos con Claude Code CLI
- Scripts de automatización
- Documentación de flujos de trabajo

## Requisitos

- [Claude Code](https://claude.ai/code)
- Git
- GitHub CLI (`gh`)

## Inicio rápido

```bash
git clone https://github.com/GinoZeta/claude-workspace.git
cd claude-workspace
claude .
```
